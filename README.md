An automated, cloud-native scouting engine that delivers a curated daily digest of **Software Engineering (SE) Internships** straight to Telegram subscribers every morning at **7:48 AM (Asia/Colombo)**.

The system prioritizes the **Sri Lankan tech ecosystem (80%+ focus)**—including early-stage startups, boutique software agencies, and established tech firms—alongside select worldwide remote fellowships.

---

## ⚡ Highlights

- **Multi-Source Live Web Scraping**:
  - **Rooster.jobs**: Extracts dynamic single-page React startup listings using headless Chromium via Playwright.
  - **ITPro.lk**: Scrapes daily verified undergraduate IT and SE internship vacancies.
  - **TopJobs.lk**: Parses the Information Technology (`SDQ`) board for active corporate trainee and junior roles.
- **AI-Powered Synthesis & Formatting**:
  - Normalizes scraped listings into clean, structured Telegram digests with tech stacks, candidate requirements, and direct apply links.
  - Multi-provider resilience: Google Gemini (dynamic model discovery) with automatic failover to NVIDIA NIM (DeepSeek) and exponential backoff retry.
- **Serverless & Zero-Cost Infrastructure**:
  - Runs 100% in the cloud via GitHub Actions cron schedules—no servers, VPS, or running local machines needed.
- **Privacy-First Subscriber Management**:
  - Users subscribe simply by sending `/start` to [@SE_intern_pissu_bot](https://t.me/SE_intern_pissu_bot).
  - Subscriber IDs are decoupled from git and stored in an encrypted private GitHub Gist, allowing the repository to remain safely public for unlimited GitHub Actions runner minutes.

## 🛠️ Tech Stack

- **Runtime**: Python 3.12
- **Automation & CI/CD**: GitHub Actions (Ubuntu Runner)
- **Scraping Engine**: Playwright (Headless Chromium), Python `urllib` & `re`
- **AI / LLM Providers**: Google Gemini API, NVIDIA NIM (DeepSeek v4.1 Flash)
- **Database / State**: GitHub Gist REST API (Encrypted Private Key-Value Storage)
- **Messaging**: Telegram Bot API

---

## 🔐 Required Secrets

Configured under **Settings ➔ Secrets and variables ➔ Actions**:

| Secret | Description |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Bot API token generated by [@BotFather](https://t.me/BotFather) |
| `TELEGRAM_CHAT_ID` | Primary administrator Telegram chat ID |
| `GEMINI_API_KEY` | Google AI Studio API key |
| `NVIDIA_API_KEY` | NVIDIA NIM API key for secondary LLM failover |
| `GIST_TOKEN` | GitHub Personal Access Token (`gist` scope) for subscriber database |
| `SUBSCRIBERS_GIST_ID` | ID of the private GitHub Gist storing the subscriber registry |

## 🤖 Usage

Anyone can subscribe to the daily morning digest:

1. Open Telegram and search for **[@SE_intern_pissu_bot](https://t.me/SE_intern_pissu_bot)**.
2. Tap **Start** or send `/start`.
3. To unsubscribe at any time, send `/stop`.
